# Research Evaluation Dashboard

Presentation-oriented mock dashboard for comparing a baseline and an agentic research system on complex qualitative research questions.

## Stack
- Next.js + React + TypeScript
- Recharts
- Lucide installed for future icon use
- Static mock data only
- No backend, database, or Python

## Run
```bash
npm install
npm run dev
```
Then open http://localhost:3000

## Pages
- Overview
- Questions
- Question Detail: Gold vs Predicted
- Reasoning & Evidence
- System Comparison
- Methodology
